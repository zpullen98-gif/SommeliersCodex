# The canon audit (question banks), 28 Sep 2026

An accuracy audit of every question in the Codex's banks (QUESTIONS, INTRO_QUESTIONS, INTRO_CLASS_TRAPQ, ADV_QUESTIONS, MASTER_QUESTIONS): a Master Sommelier examiner per batch, then a skeptic per finding who re-opens the legal texts and sources and defaults to refuted.

- `pilot-samples/`: the pilot's 178 stratified questions (15 files). `codex-pilot-confirmed.json`: its 17 confirmed defects, about one question in ten (3 wrong keys, 1 second correct option, 3 outdated, 2 ambiguous, the rest wrong facts in options or explanations).
- `codex-full/batch-001..264.json`: the other 4,213 questions, 16 per batch.
- `codex-full-audit-state.json`: where the full run stopped (the account's session limit): 158 batches examined with 97 findings, none yet verified; 106 batches not examined (listed).
- `codex-full-audit.workflow.js`: the run's script.

Fixes land on THIS branch (`canon-audit`, cut from master), never on `codex/teaching-atlas`. QUESTIONS and INTRO_QUESTIONS are generated by `rewrite/ship.py` from `rewrite/categories/*.py`: edit the modules and regenerate. ADV_QUESTIONS and MASTER_QUESTIONS are hand-authored in `js/data-advanced.js` and `js/data-master.js`: edit in place, never change an id. Ship after the atlas branch is committed, with the `?v=` and sw.js CACHE bumps.
