# Regional Field Atlas

The owner requested one coordinated release covering every existing regional
heading. This edition adds 115 regional SVGs and 14 supplementary country
SVGs while retaining the 17 established country/state overview sheets.

The reading sequence is locate, read, explain, recall. Search accepts places
and grapes; each regional map links to the same article, card deck and
question set already used by the Codex. Maps offer an enlarged view and a
numbered text key. Day and night service styles share the same controls.
Downloads are optional and separate from study records.

Geographic data provides coastlines, selected water features and reference
towns. Regional viewing windows are editorial choices, not legal polygons.
Representative dots do not imply the size or boundaries of a wine area.
The collection supports the detailed readings; it is not a cadastral,
geological or elevation survey.

Champagne and Tuscany receive newly researched notes on terroir, grapes,
viticulture, cellar decisions, service and comparison. Each new country
map receives a concise sourced study. Other maps display their existing
regional course material directly, with links to its sources and the
full reading. This release does not claim to have independently re-certified
every sentence of all earlier regional articles.

Current-rule corrections include Champagne's Chardonnay rose and
conditional Voltis distinction, Champagne release versus lees-ageing
clocks, Tuscany's dated specification changes, Casauria in Abruzzo,
Querétaro's protected Mexican wine indication and Niagara's three
regional appellations. The separate review logs record primary sources
and exact editorial scope.

The Wine Bible, third edition, is linked as companion reading. Official
appellation authorities and regulations take precedence for current
requirements. No book text or copyrighted cartography was reproduced.

## Preservation

Regional question IDs and card positions remain stable. Corrected question
wording uses its existing explicit ID where needed. Existing scores, SRS,
house records, original map joins and optional legacy map caches retain
their formats. New spoken map prompts are unscored.

## Verification

The field-atlas gate checks full coverage, region joins, coordinate bounds,
safe SVG content, exact hashes and shell/cache integration. Browser checks
cover cold routes, search, article and deck links, Back, map enlargement,
phone layout, both service themes and independent offline artwork.
The normal public release suite remains required before publication.

Final generated coverage is 129 maps with 1,284 representative locations,
at least five per map, and 52.8 MiB of optional artwork. Independent browser
measurement found no text overflow or place-key overlaps. Every SVG matches
its manifest hash and the build is deterministic.

Real service-worker tests saved Champagne and Bordeaux, loaded their
readings, disabled the network, and cold-reloaded both maps successfully.
Artwork and detailed notes remained available. Existing learning marks
and an unrelated Ledger cache were preserved.

The identity comparison retained all 1,068 regional question IDs and
1,169 flashcard positions. Source navigation, Brennan's integration and
regional content gates passed, alongside the new field-atlas gate.

## Integration with the 23 October foundations

The source now includes Claude's deeper-atlas authoring pipeline and all
1,068 pinned question IDs. The canonical content from this reviewed map
edition is preserved exactly; rebuilding the readings changes no bytes.
The planned 29 extra articles, seven country records and 43 techniques
remain unactivated. Synthetic video fixtures are test inputs only.

Exact country names cannot be captured by a future region with a longer
name, such as South West France or Southern Oregon. The authoring and
runtime resolvers share this rule and retain specific regional matches.
Reading-only articles do not show a numbered-map action. Map generation
skips them until their geography is authored; the existing Georgia map
will follow a standalone Georgia reading when that record is added.

The expanded curriculum still needs authored content, depth-aware reading
and study controls, and explicit coverage for new places before activation.
This release publishes the complete existing 115-region map collection.
